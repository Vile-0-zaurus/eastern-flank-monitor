# Manual inputs

Empty on purpose. A blank file is no data. Do not read it as zero.

Until the admin page exists, edit these by hand. One source link per row. A row with no link does not count.

`date` is the Monday of that week, `YYYY-MM-DD`.

| File | What `value` is |
|---|---|
| `o1-ukraine-war.csv` | Integer 0–4. Ukraine war status for the week. |
| `o2-us-commitment.csv` | Integer 0–4. US commitment to European defense for the week. |
| `c2-force-posture.csv` | Short note. Official intelligence report or established think tank only. |
| `h2-incident-log.csv` | One incident note. Several incidents in one week are several rows. |

The 0–4 scale is not tuned yet. Do not invent rows.
